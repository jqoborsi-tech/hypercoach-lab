# hypercoach-lab

A small lab of self-contained apps.

| Path | What it is |
|---|---|
| `index.html` | HYPERCOACH V2 — hypertrophy training coach (web app). |
| `poker-coach/` | Poker coach (web app). |
| `face-scanner/` | **ArchScan** — native iOS TrueDepth facial scanner for full-arch surgery and prosthetics. Exports OBJ/PLY/STL in millimetres with landmarks, reference planes and measurements. See [`face-scanner/README.md`](face-scanner/README.md). |
| `face-scan/` | ArchScan Viewer — browser viewer for those exports. Reads OBJ/PLY/STL plus `landmarks.json`, checks the scale, and renders the mesh. Everything stays local. |

ArchScan is for research and laboratory use. It is not a medical device.
